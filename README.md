# Achadinhos

Bot de ofertas com link de afiliado (Shopee, Mercado Livre, AliExpress e Amazon), com painel pra Windows.

**Baixar:** botão verde **Code → Download ZIP**, extraia e dê dois cliques no `Iniciar.bat`.

O passo a passo completo está no [LEIA-ME.txt](LEIA-ME.txt).

Suas chaves ficam só no seu PC (`segredos.json` / `.env`). Nunca suba esses arquivos.
